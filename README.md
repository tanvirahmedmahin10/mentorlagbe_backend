# 🎓 MentorLagbe Backend

A RESTful backend API for **MentorLagbe**, a tuition and academic mentorship platform that connects students with tutors across Bangladesh. It handles tuition management, student applications, user authentication, role-based authorization, and Stripe subscription payments.

## ✨ Features
- Manage users and user roles (Student, Tutor, and Admin).
- Create, update, delete, and retrieve tuition listings.
- Search and filter tuition batches by subject, class level, and teaching mode.
- Manage student applications and application statuses.
- Role-based authorization with session token verification.
- Admin controls for approving and rejecting tuition posts.
- Manage user profiles and academic information.
- Stripe Checkout payment verification and subscription management.
- Store users, tuitions, applications, and payments in MongoDB.

## 🛠️ Technologies & Packages
- Node.js
- Express.js
- MongoDB
- Stripe
- CORS
- dotenv
